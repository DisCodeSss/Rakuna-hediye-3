# Rakunun Küçük Sırrı

Kişisel hediye sitesi. GitHub Pages ile yayınlanabilecek şekilde hazırlanmıştır.

## Dosyalar
- `index.html` — sayfalar ve içerik
- `style.css` — tasarım/animasyonlar
- `script.js` — geçişler, isim, balon seçimleri
- `assets/rakun.png` — rakun görseli
- `assets/balonlar.png` — balonlu arka plan
- `assets/song.mp3` — yerel ses dosyası

## GitHub Pages
1. GitHub'da yeni bir repository oluştur.
2. Bu klasördeki dosyaların tamamını repository'ye yükle.
3. Settings → Pages → Deploy from a branch → `main` / `/root` seç.
4. Oluşan GitHub Pages bağlantısını paylaş.

### Ses dosyası hakkında
Bu projede yüklediğin ses dosyası yerel asset olarak kullanılıyor. Telif hakkı sana ait olmayan bir müziği herkese açık bir GitHub repository'sinde dağıtmak yerine, kullanım/paylaşım hakkına sahip olduğun bir ses dosyası kullanman daha güvenlidir.
